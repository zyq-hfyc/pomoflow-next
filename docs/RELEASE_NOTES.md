# PomoFlow 发布说明

> 面向用户的版本说明。每版本含:新增 / 修复 / 已知事项 / 升级说明。
> 开发过程明细见 [协作任务清单.md](./协作任务清单.md),本文件只保留用户视角的要点。

## 0.2.0(2026-09-04)

自 0.1.0(2026-08-20)以来的全部增量。一句话:**从单机工具升级为「本地优先 + 云端同步」的多端体系,移动端首发**。

### 新增 · 桌面端

- **账号体系**:注册 / 登录 / 修改密码 / 多设备会话管理与吊销;
  账号中心(头像、个性签名、登录设备记录、账号注销冷静期)
- **云同步**:任务(含子任务)/ 项目层级 / 标签(含任务-标签关联)/
  番茄会话 / 手账 / 复盘(日/周/月/年)/ 座右铭 / 通知文案模板 /
  计时参数,全实体 Last-Writer-Wins 合并
- **自动同步**:启动时自动拉取 + 可配置周期的定时后台同步
- **同步冲突可视化**:LWW 落库记录 + 冲突列表页,修改不再静默丢
- **任务管理补齐**:搜索与筛选、垃圾箱(软删除回收站,可还原/彻底删除)、
  子任务、任务项目归属
- **统计页接入真实番茄数据**;CSV 导出
- **年度复盘**:手账模式第四粒度(周只读 → 月编辑 → 年编辑)
- **同步完成后各页面免重启刷新**:别端改动在页面开着时即时可见
- **随手记视图**:journal 实体桌面读写闭环

### 新增 · 移动端(首发)

- **Flutter 移动端首个正式版**(release 签名,arm64 包约 20.3MB):
  本地优先 + 云端同步,与桌面端数据互通
- 专注计时(番茄 / 休息 / 长休息,参数可配)
- 任务:子任务、项目 3 级层级、标签、6 种重复规则、到期日/提醒
- 手账 + 四粒度复盘(日 / 周 / 月 / 年,均可选日期回看续写)
- 统计页(趋势 / 总览 / 项目分布)+ CSV 导出
- 座右铭:自定义逐条轮播 + 50 条内置名言,作者署名与桌面一致
- 本地通知提醒(到点触发,含 6 套文案模板 + 自定义)
- 垃圾箱、快速新建(任务/小记/待办/愿望/计划/复盘)
- 账号中心:头像、个性签名、数据导出、注销冷静期、会话管理
- 后台自动同步(workmanager,默认关闭可开启,30 分钟周期)

### 修复

- 桌面 v2 独有缺陷 B1–B9 全部修复
- 移动端真机验证四轮 E2E 修复闭环(登录设备去重、毒数据三连修等)
- 移动端用户反馈 3 批:底部抽屉顶部灰横线、座右铭无署名/无法切换、
  复盘入口点了没反应、通知文案蒙层、已完成任务开始入口、日历中文化等
- 桌面 UI:修复 3 处图标样式静默失效(任务选择器箭头不旋转、同步按钮
  不转圈、子任务加号颜色);代码检查(svelte-check)基线清零

### 已知事项

- 云同步服务当前为自部署(内网 / VM);正式公网部署(域名 + HTTPS)待定
- 桌面覆盖安装升级;移动端暂无应用商店分发,以 APK 直装为准

### 升级说明

- **桌面**:直接运行 `PomoFlow_0.2.0_x64-setup.exe` 覆盖安装,本地数据保留
- **移动端**(从 0.1.0 debug 版切换):
  1. 卸载前在旧版手动「立即同步」并确认成功(**唯一保数据机会**)
  2. 卸载 debug 版 → 安装 `app-arm64-v8a-release.apk`(必须 arm64 包)
  3. 重新登录 → 手动同步,数据从服务端恢复
