# 构建产物清理操作步骤

> 本仓库源码只有几十 MB,但 `target/`(Rust 编译缓存与产物)会随开发不断膨胀到
> **20 GB+**。本文是安全清理的标准流程 —— 什么能删、什么必须留、删了有什么代价。

## 一、空间都在哪(认知地图)

| 目录 | 体积量级 | 性质 | 能删吗 |
|------|---------|------|--------|
| `target/` | **GB ~ 20GB+** | Rust 编译缓存/中间产物/打包输出 | ✅ 可随时删,下次编译自动重建 |
| `apps/desktop/ui/node_modules/` | ~200-300MB | 前端依赖(npm 安装) | ⚠️ 可删,恢复要 `npm install`(国内较慢),一般不动 |
| `.git/` | ~百 MB | 版本历史 | ❌ **绝对不删** |
| `apps/desktop/ui/dist/` | 几 MB | 前端构建产物(**已入库**,Tauri 打包用) | ❌ 不删(是仓库的一部分) |
| 源码(crates/apps/services/tools/docs) | 几 MB | — | ❌ 不删 |

## 二、标准清理流程(推荐)

### 第 0 步:确认没有进程占用

桌面应用或 `tauri dev` 在跑会锁住 `target/` 里的 exe,删除会失败。先关掉
PomoFlow 应用和所有终端里的 `cargo`/`npm run dev`。

```bash
# Windows Git Bash:确认没有 pomoflow 进程(输出"没有运行的任务..."即安全)
tasklist //FI "IMAGENAME eq pomoflow-desktop.exe"
```

### 第 1 步:抢救两个珍贵产物(在 target/ 里!)

删除 `target/` 前先挪走这两样到 `artifacts/`(已 gitignore):

```bash
mkdir -p artifacts

# ① NSIS 安装包(如有;每次 tauri build 重新生成)
mv target/release/bundle/nsis/*.exe artifacts/ 2>/dev/null || true

# ② 服务器部署包(如有;随时可用 pack-deploy.sh 重打,不挪也行)
mv target/pomoflow-sync-deploy-*.tar.gz artifacts/ 2>/dev/null || true
```

> 没有这两个文件(没打过包)就跳过本步。

### 第 2 步:删除 target/

```bash
# 方式 A(标准):cargo 官方清理命令
cargo clean

# 方式 B(等价):直接删
rm -rf target
```

只删一半的场景(想保留 release 产物、只清调试缓存):

```bash
rm -rf target/debug          # 只清 debug(日常开发的主要膨胀源)
```

### 第 3 步(可选):回收 node_modules

磁盘极度紧张才做,恢复需重新下载依赖:

```bash
rm -rf apps/desktop/ui/node_modules
# 恢复:
cd apps/desktop/ui && npm install
```

## 三、删掉的代价

- `cargo` 全量重建:下次第一次 `cargo check` ~1-2 分钟,`cargo test` ~3-5 分钟,
  `tauri build`(release)**~5-10 分钟**——属正常代价,不是损坏。
- `artifacts/` 里的安装包/部署包**不受影响**(已挪出)。
- 部署包丢了也不怕:`bash services/sync-server/pack-deploy.sh` 随时重打。
- 仓库(git)完全不受影响:`target/` 本来就在 .gitignore 里。

## 四、什么时候该清

- 磁盘空间告警(C 盘红色);
- 升级了 Rust 工具链或大版本依赖(旧缓存全部失效,留着只占地方);
- 长期没跑 release 构建,`target/release` 吃灰;
- 打包发行完成后(安装包已挪到 `artifacts/`)。

## 五、Windows 常见问题

- **删除报"文件被占用"**:九成是 PomoFlow 应用/VSCode 的 rust-analyzer/
  终端里的 cargo 还开着 —— 全关掉再删;实在找不到就重启后再删。
- **删除很慢**:21G、几十万个小文件,Windows 上删 5-10 分钟正常,耐心等。
- **`cargo clean` 和手动删选哪个**:等价;命令行卡住就换资源管理器直接删
  `target` 文件夹,效果相同。
