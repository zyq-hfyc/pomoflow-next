# 真机验证清单(统一汇总 · 2026-08-25)

> **用途**:Windows 主机只能跑单测/analyze/Web 预览,mobile 的 native 同步链路
> 一直没在真设备上端到端跑过。本清单汇总**所有待真机验证项**,按批次归组,
> 一次性统一验证。详细操作步骤见各专项 runbook(文中链接)。

## 0. 前置准备(一次性,约 10 分钟)

| 项 | 操作 | 预期 |
|----|------|------|
| APK 构建 | 见 [`B-Phase-3 runbook` §1](./B-Phase-3安卓真机验证runbook.md) | `app-debug.apk` 产出 |
| USB 调试 | 手机开发者模式 + USB 调试 + 授权 | `adb devices` 显示 `device` |
| 装机 | `adb install -r apps/mobile/build/app/outputs/flutter-apk/app-debug.apk` | `Success` |
| 服务端 | VM 上 sync-server 运行中 | `curl http://<vm-ip>:8080/healthz` → `{"ok":true}` |
| 桌面端 | 同一账号已登录(用于双向验证) | 桌面任务列表可操作 |

> 手机与 VM 同一局域网;App 登录页服务器地址填 `http://<vm-ip>:8080`。

## 1. 登录与账号(P3d 批)

- [ ] 登录成功,进入「专注」首页,底部 Dock 四屏正常
- [ ] 「我的」页显示用户名 / 邮箱 / 头像字母占位
- [ ] 头像上传:相册选图 → 显示圆形头像(重新进入仍保留)
- [ ] 数据导出:分享面板弹出 JSON 备份文件
- [ ] 登录设备列表:出现手机设备名(Android 品牌+型号)
- [ ] 退出登录 → 回登录页;重登数据仍在

## 2. 任务同步双向闭环(P1 多实体批)

- [ ] **桌面 → 手机**:桌面建任务(标题 `from-desktop`)→ 手机「我的」→
      立即同步 → 手机任务页出现该任务,状态行显示「拉取 1应用」
- [ ] **手机 → 桌面**:手机把该任务勾选完成 → 桌面立即同步(或等自动)→
      桌面该任务变已完成
- [ ] **手机编辑**:手机上编辑该任务标题 → 同步后桌面标题更新
- [ ] 服务端核对(可选):
      `docker exec <pg> psql -U pomoflow -d pomoflow -c
      "SELECT entity, entity_id, revision, device_id FROM snapshots ORDER BY updated_ms DESC LIMIT 5;"`
      → 有 `entity='task'` 且 device_id 为手机名的行

## 3. 软删除同步(P2 批)

- [ ] **手机删 → 桌面消失**:手机任务详情 → 删除任务 → 二次确认 →
      列表消失 → 同步后桌面该任务消失
- [ ] **桌面删 → 手机消失**:桌面删一个任务 → 手机立即同步 → 手机列表消失
- [ ] **不复活**:删除后两边各同步 2 轮以上,任务不再出现
- [ ] 删除当前专注任务:专注屏自动解除关联(切回「选择任务」态)

## 4. 专注落 session(P1 批)

- [ ] 手机专注屏选任务 → 开始 → 自然走完(25 分钟)→「今日番茄」+1
- [ ] 短休息 / 长休息走完:**不**计今日番茄(P1 行为修正点)
- [ ] 「我的」→ 立即同步 → 状态行「推送 1接受」(session 行)
- [ ] 服务端核对:`entity='pomodoro_session'` 行出现
- [ ] 桌面端统计页能看到手机产生的番茄(桌面拉到 session)

## 5. 统计页真数据(本批 P2)

- [ ] 统计页六维度切换(今天/本周/本月/本季/半年/全年)数字即时变化
- [ ] 4 统计卡:专注分钟/番茄数/完成任务/日均分钟 与实际专注记录一致
      (今天维度 = 当日分钟;番茄数 = 当日 session 数)
- [ ] 亮点行:活跃天数 / 最长连续 / 环比上期(首次使用显示 `—`)
- [ ] 趋势图:近 7 天每日分钟,今天一柱与「今日番茄×时长」一致
- [ ] 项目分布:环形 + 图例 = 各项目分钟占比;无记录时显示占位文案
- [ ] **同步后即见**:「我的」页立即同步拉下桌面 session 后,**不重启**
      切到统计页数字即更新(pull 后内存刷新,审查修复项)
- [ ] **两端一致**:同一账号桌面统计页与手机统计页同日番茄数相同
      (计数口径对齐:自然完成 + 关联任务的会话才计)
- [ ] 计数口径行为:不选任务直接专注走完 → 「今日番茄」**不**加 1
      (与桌面端一致;会话仍落库可查)

## 6. 后台自动同步(workmanager 批)

**MIUI 前置(必做,否则周期任务被系统杀)**:

- [ ] 设置 → 应用设置 → 应用管理 → PomoFlow → 省电策略 → **无限制**
- [ ] 安全中心/手机管家 → 应用管理 → 权限 → 自启动 → PomoFlow **开启**

**验证**:

- [ ] 「我的」→ 数据同步卡 → 打开「自动同步」开关 → 提示「每 30 分钟 · 联网时后台同步」
- [ ] 桌面端建任务 → 手机**退到后台锁屏** → 30 分钟后解锁 → 任务自动出现
      (回前台即刷新,无需手动同步)
- [ ] 关闭开关 → 不再后台同步
- [ ] (排查用)电脑跑 `adb logcat -s flutter`,后台周期到点时出现
      `[bg-sync] 已同步 · …` 日志

## 7. 异常路径(可选)

- [ ] 断网状态点「立即同步」→ 显示同步失败信息,本地操作不受影响
- [ ] 恢复网络再同步 → 补推成功(pending 队列不丢)
- [ ] 服务器地址配错 → 登录页报「无法连接服务器」类错误,不崩溃
