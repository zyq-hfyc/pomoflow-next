## 0. 前置准备(一次性,约 10 分钟)

| 项 | 操作 | 预期 |
|----|------|------|
| APK 构建 | 见 [`B-Phase-3 runbook` §1](./B-Phase-3安卓真机验证runbook.md) | `app-debug.apk` 产出 |
| USB 调试 | 手机开发者模式 + USB 调试 + 授权 | `adb devices` 显示 `device` |
| 装机 | `adb install -r apps/mobile/build/app/outputs/flutter-apk/app-debug.apk` | `Success` |
| 通知权限 | 首次点专注页铃铛 → 允许(A/B/C 组的通知项都依赖) | 铃铛 🔔 |
| 服务端(B/C 组) | VM 上 sync-server 运行中 | `curl http://<vm-ip>:8080/healthz` → `{"ok":true}` |
| 桌面端(B/C 组) | 同一账号已登录(用于双向验证) | 桌面任务列表可操作 |

> 手机与 VM 同一局域网;App 登录页服务器地址填 `http://<vm-ip>:8080`。
