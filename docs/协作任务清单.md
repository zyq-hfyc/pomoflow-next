## 2026-08-23 · 登录后「我的」头像昵称空白(提交 554e253)

> 用户反馈:登录后进入「我的」,头像/用户名/昵称/邮箱都没显示。

- ✔ **根因定位**:服务端 `services/sync-server/src/auth_handlers.rs` 的 `AuthTokens` 结构

  ```rust
  pub struct AuthTokens {
      pub user_id: String,
      pub username: String,
      pub access_token: String,
      pub refresh_token: String,
      pub expires_in: i64,
  }
  ```

  只有 `username`,**没有** `display_name`/`email`。客户端 `_onAuthSuccess` 直接 `resp['display_name']` / `resp['email']`,永远 null → `auth.shownName` 为空 → `_ProfileHead` 渲染「?」+ 空昵称 + 不显邮箱
- ✔ **客户端侧修复**(提交 554e253,不动服务端避免重编重部):
  - `_onAuthSuccess` 在 `saveTokens` 之后多走一步:`ApiClient.instance.get('/v1/auth/profile')`
  - profile 含 `username` / `display_name` / `email` / `bio`,覆盖 login 返回的薄 `username`
  - catch 网络/profile 暂时拉不到:username 留 login 给的、displayName/email 留 null,下次启动 `initialize()` 再补;顶栏头像降级「?」
- ✔ **覆盖 4 个入口**:`login` / `loginEmail` / `register` / `registerEmail` 全部走 `_onAuthSuccess`
- ✔ **保留原有路径**:AccountPage 改昵称走 `updateDisplayName` 不受影响;启动 `initialize()` 也仍 fetch profile
- ✔ **验证**:analyze 0 / test 3/3;实机验证需真 sync-server(VM 上重打 build)
